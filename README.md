这本来是我想给一个视频制作组做的字幕生成监控后台。

后来想想，反正都开始做了，干脆把平时剪视频最烦的那堆事情一起塞进去。于是我稍微让 Codex 多干了点活，最后弄出来了一个本地跑的素材台。不碰剪辑软件，只负责把素材、配音、文案和下载到处乱飞的东西收拾好。

## 现在能干什么

### 1. 音乐

**现在的 UP 找音乐真的很麻烦**：想听原曲得翻好几个平台，找到歌名了也不一定能直接拿到音频

素材台接了 GD Studio 的搜索。搜歌名或者音乐人，试听一下，选中就能下到当前项目的“音频”文件夹。下完也会自动出现在素材库里，后面想再拖出来用不用重新找。

### 2. 视频

本机装了 BBDown 以后，输入 BV 号就能看预览、加到下载栈，然后按最高可用画质下载到项目里的“视频”文件夹。

还有个我自己觉得挺好用的功能：把某个 UP 的主页链接和想找的视频标题丢进去，它会在那个主页里找标题和简介相近的视频。至少不用一页页翻动态了ww

### 3. 素材库和素材栈

**整理素材太麻烦了！东一个西一个什么雷霆想要以前的素材找起来太麻烦了！**

素材不管原来放在哪，只要加进“来源”，该项目就会自动检测里面的音频、视频和图片。平时可以按名字、标签、文件夹搜，也能按修改时间、大小、类型排。

找到合适的先塞进素材栈。之后直接从素材台或者素材栈拖进剪辑软件就行，没必要每次都打开那个置顶小窗。小窗只是剪辑的时候图个方便。

每个视频项目会有自己的“视频 / 音频 / 图片 / 封面”文件夹。音乐和视频下载完成后会自己归类进去，素材台也能继续找到它们。

### 4. 配音、文案和字幕

这部分还是最初想做的东西。群里收到配音和文案后，可以按命名规则配对，后台能看到文件有没有收齐、字幕有没有在跑，也能手动改文案、改文件名、重新配对。

音频和文案都没问题时，就生成相邻字幕没有空隙的 SRT。成了以后能自动发回工作群。反正剪视频最怕的就是“这个文案到底配的是哪个音频”，能少问几次人就已经赢了。

## 关于素材和下载

这个工具只负责整理本机文件、调用已经装好的工具和第三方网站，本身不带任何音乐、视频、图片、账号内容或素材包。

GD Studio、哔哩哔哩、BBDown、Electron、FFmpeg 都是各自的东西，和这个项目没什么官方关系。网站哪天改了、接口挂了、下载不了或者规则变了，也只能跟着改，没法保证一直好用。

音乐和视频能不能下载、能不能剪进视频、能不能发出去，最后还是得看素材本身的授权和平台规则。别因为这里能搜到、能下到，就当成它自动变成可商用了。署名、转载、商用这些该看的还是得看，别拿去搬运或者乱传。

另外，项目文件和素材记得自己备份。文件夹拖错、配置改坏、第三方服务抽风这种事谁都拦不住，重要的东西多留一份总没错。
